# Archive — brut du projet

Contenu brut du déroulé du projet (anonymisé) :

- `conversation.md` — résumé chronologique complet : cahier des charges,
  adressage, problèmes rencontrés, solutions, état final, tests.
- `transcript-brut.md` — transcript message par message des échanges.

Les 32 captures d'écran d'origine ne sont pas archivées ici : elles
contenaient des adresses réelles non anonymisables. Le texte est autosuffisant.

La résolution du dernier point ouvert (DHCP) est documentée proprement dans
`../docs/03-diagnostic.md` (section 8) et la méthode de test dans
`../procedures/test-dhcp.md`.
